# Płatność za usługę — interaktywny prototyp

Publiczna wersja demonstracyjna bezpośredniej płatności za usługę. Pokazuje przejście od oferty przez checkout do automatycznego potwierdzenia zamówienia i faktury.

To prototyp: nie pobiera płatności, nie zapisuje danych i nie wystawia prawdziwych faktur.
