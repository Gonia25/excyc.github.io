# RITUA — demonstracyjny sklep Shoper

RITUA to kompletna, responsywna wersja demonstracyjna sklepu przygotowana jako przykład powtarzalnego wdrożenia na platformie Shoper.

**Demo:** https://gonia25.github.io/ritua-shoper-demo/

## Zakres pokazany w demo

- gotowa architektura strony głównej sklepu,
- responsywny nagłówek i menu mobilne,
- wyszukiwarka z podpowiedziami,
- filtrowanie i sortowanie produktów,
- szybki podgląd produktu,
- ulubione zapisywane na urządzeniu,
- działający koszyk z ilościami i progiem darmowej dostawy,
- formularz newslettera z walidacją,
- kompletna stopka z treściami informacyjnymi,
- wersje desktop, tablet i mobile.

## Zgodność ze zleceniem

Demo pokazuje jakość konfiguracji, dopasowania szablonu, uzupełnienia treści oraz kontroli przed przekazaniem sklepu. Właściwa realizacja odbywa się bezpośrednio w panelu Shoper na koncie klienta, z użyciem wskazanego szablonu, materiałów i wzoru sklepu.

Wprowadzanie produktów nie jest częścią deklarowanego zakresu. Produkty RITUA są wyłącznie treścią demonstracyjną potrzebną do sprawdzenia wyglądu standardowych modułów sklepowych.

## Uruchomienie

Plik `index.html` jest samodzielny i może zostać otwarty bez procesu budowania. Do lokalnego podglądu deweloperskiego:

```bash
npm install
npm run dev
```

Szczegółowa kontrola wdrożenia znajduje się w pliku [SHOPER_QA_CHECKLIST.md](SHOPER_QA_CHECKLIST.md).
