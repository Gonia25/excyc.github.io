# Destryfikatory.pl — interaktywna wizualizacja

Samodzielna, statyczna wersja wizualizacji działania destryfikatorów. Nie wymaga logowania, konta ani serwera aplikacyjnego.

## Uruchomienie

Otwórz `index.html` w przeglądarce albo umieść cały katalog na dowolnym hostingu statycznym.

## Zawartość

- interaktywna animacja hali 10 m / 20 m,
- pięć animowanych destryfikatorów,
- przejście od stratyfikacji do równomiernej temperatury,
- responsywny układ,
- osobne pliki SVG elementów sceny.
