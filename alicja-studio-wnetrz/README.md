# Alicja Studio Wnętrz — demo

Live demo: https://gonia25.github.io/excyc.github.io/alicja-studio-wnetrz/

A polished, responsive concept site for the interior-architecture studio described in the Useme advertisement. The temporary professional identity can be replaced with the studio’s official name, logo, project photography and contact details during handoff.

## Included

- elegant, minimalist presentation tailored to interior architecture
- home, studio/about, services, portfolio, process and contact sections
- responsive desktop, tablet and mobile layouts
- filterable portfolio and full-screen project previews
- enquiry form with validation and transparent demo behavior
- location module ready for the studio address or map
- privacy and cookie controls
- foundational SEO metadata and structured data
- accessible navigation, keyboard interactions and reduced-motion support

## Production handoff

The final WordPress implementation would retain this visual system while adding the owner-editable portfolio, spam protection, Analytics, Search Console, backups, SSL/security configuration and the supplied brand assets.
